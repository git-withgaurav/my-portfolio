# ANTIGRAVITY — Creative Developer Portfolio

A premium, high-end portfolio website built with **React**, **GSAP**, and **Framer Motion**. Featuring fluid typography, horizontal scrolling, magnetic interactions, and a custom "Googly Eyes" cursor.

## ✨ Features
- **Custom Googly Eyes Cursor**: A playful, living cursor that follows the mouse and reacts to interactions.
- **Horizontal Scroll Section**: A smooth, GSAP-powered horizontal gallery.
- **Velocity-Sensitive Marquee**: Infinite looping brand marquee that reacts to scroll speed.
- **Variable Typography**: Fluid font-weight animations synced with scroll position.
- **Global Mesh & Grain**: Premium photographic background with a tactile film grain overlay.
- **Functional Contact Form**: Integrated with **Web3Forms** for zero-backend email delivery.

## 🛠️ Tech Stack
- **Framework**: React.js
- **Styling**: Vanilla CSS (Modern CSS Variables)
- **Animations**: GSAP, Framer Motion, ScrollTrigger
- **Smooth Scroll**: Lenis
- **Form Handling**: Web3Forms

## 🚀 Getting Started

### 1. Installation
```bash
npm install
```

### 2. Set up Web3Forms
- Get your access key at [web3forms.com](https://web3forms.com/).
- Open `src/components/ContactForm.jsx` and replace `'YOUR_ACCESS_KEY_HERE'` with your key.

### 3. Run Locally
```bash
npm run dev
```

## 📦 Deployment
This project is optimized for deployment on **Vercel**, **Netlify**, or **GitHub Pages**. Simply connect your GitHub repository to your preferred platform.
